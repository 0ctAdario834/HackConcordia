# Studious
If you wanted to find a place to study, you would first need to Google "places to study", and then hope that the search engine offers you the kind of place you're looking for. For example, sometimes you might be looking for a quieter place, like a library, or a place you can eat, like a café. Though the search engine will sometimes hide certain options under mountains of blogs and articles. And other times, the results that appear turn out to be too far away. <br>
And if you searched "places to study" using Google Maps, you could get results like cafés, but other types of places might remain buried.
## Overview
Our website allows the user to add locations along with their names, address, and multiple tags. <br>
Users can then search the locations by nearest distance or by tags.
